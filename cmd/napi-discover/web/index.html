napi-discover

Поиск плат NAPI в сети, SSH и консоль UART.

«Искать»: платы с avahi: с сервисом napi-avahi (модель, SoC, роль) и с голым avahi в прошивке (проверяются по SSH, показываются только «NAPI?»). «Сырой поиск»: всё на порту 22, кроме Windows и MikroTik, для плат совсем без avahi; NAPI всегда сверху. «Консоль»: UART платы через USB-переходник, 1500000 8N1, выход Ctrl+]. napiconfig, SSH, influxdb, grafana, donoff: выбранная в таблице плата; двойной щелчок по строке: SSH, Ctrl+C: копировать IP. Зелёные строки: napi-avahi, жёлтые: «NAPI?» (голый avahi или сырой поиск).

Галочка «Моё имя»: дайте плате своё имя. Отмеченные платы идут первыми, «Искать» проверяет их и без avahi, плата узнаётся по ключу SSH и MAC, даже если сменился IP или имя в сети. Не найденная плата остаётся серой строкой внизу. Двойной щелчок по имени: переименовать. Модель и SoC отмеченной платы без napi-avahi: двойной щелчок по ячейке «Модель» или «SoC». Список хранится на этом компьютере: ~/.config/napi-discover/boards.json.

Кнопка «Искать» находит плату, на которой работает avahi-daemon. Модель, SoC и роль в таблице даёт сервис napi-avahi: apt install napi-avahi из репозитория napilab: repo.napilab.ru. Исходники и подключение репозитория: github.com/lab240/napi-avahi. Свежая версия программы: github.com/lab240/napi-avahi/releases.
